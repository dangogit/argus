# Product

## Register

product

## Users

Operators and maintainers running Argus over real software projects. They arrive during active work, incident follow-up, or go-live proof, and need immediate truth about which agents are alive, what each worker did, and what is still pending.

## Product Purpose

Argus is a self-hosted company of AI agents for software operations. The dashboard exists to make agent activity visible: live system state, worker queues, recent runs, proposed fixes, alerts, and pending operator action.

## Brand Personality

Watchful, technical, controlled. Argus should feel like a mission control surface for private agents, not a generic admin table.

## Anti-references

Do not make the dashboard a flat stack of identical cards, a bland SaaS admin page, a decorative sci-fi toy, or a table-only log viewer. The current card feed is itself an anti-reference for the live operator dashboard.

## Design Principles

- Show agents as actors, not rows.
- Put live operational truth above documentation-like explanation.
- Make pending work and blocked states impossible to miss.
- Use motion only to communicate liveness and focus.
- Keep every futuristic element tied to real state.

## Accessibility & Inclusion

Target WCAG AA contrast. Keyboard navigation must reach every worker. Motion must respect reduced-motion preferences. Status must not rely on color alone.
